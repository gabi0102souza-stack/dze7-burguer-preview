# DZE7 Burguer · conceito de site

Conceito independente de website para apresentação ao DZE7 Burguer (Vila Formosa, São Paulo). Prévia não aprovada pela empresa.

- Identidade tirada do Instagram [@dze7burguer](https://www.instagram.com/dze7burguer/): logo grafite com o burger, Kombi vermelha e creme "Desde 2016", placa amarela de estrada, parede vermelha e camisas floridas.
- Imersão ligada à proposta da casa, o **rodízio todo dia**: uma estrada em scroll horizontal onde a Kombi "come" os burgers, com contador de rodadas e fome-ômetro.
- Cardápio com preços do cardápio digital da casa (dze7.com.br/menu).

HTML, CSS e JavaScript puros. Abra `index.html` ou publique pelo GitHub Pages.
